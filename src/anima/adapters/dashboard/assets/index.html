イベントの読み方名前・主な項目・異常の見分け方

対象.動作 の順で読みます。failed は失敗、skipped は条件により実行しなかった記録です。

persona.*
queued 処理待ち、processed 応答処理完了、failed 応答処理失敗。
openai.*
request.started API呼び出し開始、response.completed 完了。tool.started / completed / failed はモデルが選んだツール、その安全な引数要約、結果です。
image_generation.* / drawing.*
image_generation.completed は画像モデルによる生成完了、drawing.saved / failed は生成画像の保存結果です。
native_tool.*
モデルが使用したネイティブツールの実行結果です。
inventory.*
持ち物の管理操作。dashboard.downloaded / deleted は管理画面からのダウンロードまたは削除の監査記録です。
plugin_job.*
プラグインの非同期ジョブ。queued / started / completed / failed / cancelled で状態遷移を確認できます。
research.saved
検索メモを会話ログへ保存した記録。検索時点・要約・出典は上のRESEARCH欄で確認できます。
maintenance.*
昼寝の要約、睡眠整理、週次振り返りの完了／失敗。rejected は保存前の検証で棄却された結果です。種類は operation で確認します。
reaction.* / face.*
一般会話へのリアクション判断と、返信に添える表情。decided action=none は正常な無反応です。
proactive.*
一般会話へ自発的に加わる判断・送信・抑止・失敗。targetは発話のきっかけになった投稿です。
self_time.*
低頻度の「自分の時間」。started / completed / failed / interrupted / skippedを記録します。Tool操作は会話と共通のopenai.tool.*に記録され、operation=self_timeで識別できます。発話せず、気分・自分の記憶・持ち物へ反映されます。
voice.*
読み上げの待機・合成・完了・中止・失敗・再接続。skipped の理由は reason に出ます。
music.*
楽曲の再生開始・完了・停止・失敗。曲は title または track_id で識別します。
reminder.*
単発リマインダーの登録・取消・通知・失敗。識別子は reminder_id です。
operation.retry
一時障害からの再試行。繰り返す場合は operation と reason を確認します。
discord.reply.recovered
再起動後、送信済みの返信を発見して状態だけ復旧した記録です。二重送信ではありません。

よく見る項目duration_ms 処理時間 · queue_wait_ms 待ち時間 · depth 待ち件数 · tool_name 選択ツール · round API往復番号 · error_type 失敗種別 · reason 中止／省略理由
